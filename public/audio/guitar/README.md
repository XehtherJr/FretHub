# Acoustic guitar samples

These recordings are the steel-string acoustic guitar samples from the
[Discord SFZ General MIDI Bank](https://github.com/sfzinstruments/Discord-SFZ-GM-Bank),
recorded by **Jeff Learman** on a 2017 Martin HD28 Vintage Series guitar.
The source instrument's SFZ file declares the samples **Creative Commons CC0**:
https://creativecommons.org/publicdomain/zero/1.0/

The fifteen WAV files are unchanged; they have been renamed to their MIDI
pitch centers (40–83) for use by FretHub's browser sampler. Notes between
samples are transposed by the Web Audio API, with a small per-recording
pitch correction to make the reference notes accurate. No sample-server request or
user data is involved.
